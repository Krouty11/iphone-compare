# iPhone Compare — MVP

A mobile-first, free-to-host Progressive Web App prototype.

## Files
- `index.html` — app shell
- `styles.css` — responsive UI
- `app.js` — comparison data + comparison engine
- `manifest.webmanifest` — Add to Home Screen metadata

## Next build steps
1. Expand the iPhone database from the prototype models to the full lineup.
2. Add verified sources and source dates to each specification.
3. Build the terminology/explanation database.
4. Add search, filters, favorites, saved comparisons, and more categories.
5. Deploy to a free HTTPS host so Safari can install it as a PWA.
